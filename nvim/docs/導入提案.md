提案プラグイン一覧
Bypass（便利系）

 jghauser/mkdir.nvim — 存在しないディレクトリへのファイル保存時に自動でディレクトリ作成。ただし init.lua に既に auto-mkdir の autocmd がある場合は不要
 nacro90/numb.nvim — :123 のように行番号を入力中にリアルタイムでその行をプレビュー表示

Motion（移動系）

 [ ]rhysd/clever-f.vim — f/t モーション強化。; の代わりに f 連打で次のマッチへ移動。注意: LSP キーマップが fd, fi, fr, ft なので競合する可能性あり
 haya14busa/vim-edgemotion — <C-j>/<C-k> でコードブロックの端へジャンプ
 haya14busa/vim-asterisk — * 検索の強化。カーソル位置を維持したまま検索
 skanehira/jumpcursor.vim — 画面上の任意の位置へ少ない打鍵で移動

日本語入力

 lambdalisue/vim-kensaku — ローマ字入力で日本語テキストを検索
 lambdalisue/vim-kensaku-search — vim-kensaku を / 検索に統合

UI 改善

 rcarriga/nvim-notify — 通知をフローティングウィンドウで表示（vim.notify の置き換え）
 folke/noice.nvim — コマンドライン・メッセージ・通知を全面的にモダン化（nvim-notify + nui.nvim 依存）
 j-hui/fidget.nvim — LSP の起動・処理状況をステータスライン横にプログレス表示
 matsui54/denops-popup-preview.vim — ddc 補完候補のドキュメントプレビュー表示
 matsui54/denops-signature_help — 関数呼び出し時に引数のシグネチャをポップアップ表示

視認性向上

 shellRaining/hlchunk.nvim — インデントガイド・チャンクハイライト表示
 gen740/SmoothCursor.nvim — カーソル移動をアニメーションで視覚化
 unblevable/quick-scope — f/t で最短到達できる文字をハイライト。clever-f.vim と相性が良い
 MeanderingProgrammer/render-markdown.nvim — Markdown をバッファ内でリッチにレンダリング
 m-demare/hlargs.nvim — 関数の引数をハイライト表示
 chentoast/marks.nvim — マーク位置をサイン列に表示
 andersevenrud/nvim_context_vt — 閉じ括弧の後ろに対応する開始行をバーチャルテキスト表示

Treesitter 連携

 JoosepAlviste/nvim-ts-context-commentstring — JSX 内など埋め込み言語で正しいコメント構文を使う（Comment.nvim と連携）

編集支援

 uga-rosa/ccc.nvim — カラーコード（#FF0000 等）をその場で視覚的に編集・ピッカー表示
 ysmb-wtsg/in-and-out.nvim — Insert モードで囲み文字（括弧・クォート）の外へワンキーで脱出

ddc 追加ソース・フィルター

 Shougo/ddc-source-cmdline — コマンドラインモードでの補完
 Shougo/ddc-source-cmdline-history — コマンド履歴からの補完
 Shougo/ddc-source-rg — ripgrep を使った補完（導入済みなら不要）
 tani/ddc-fuzzy — ファジーマッチングフィルター
 Shougo/ddc-filter-converter_remove_overlap — 重複候補の除去

ステータスライン

 nvim-lualine/lualine.nvim — 高機能ステータスライン（init.lua の自作ステータスラインを置き換え）
 akinsho/bufferline.nvim — バッファをタブバーとして表示

ターミナル

 Shougo/deol.nvim — Neovim 内ターミナル管理（denops 製）
