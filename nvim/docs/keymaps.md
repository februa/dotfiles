# キーマップ・プラグイン操作リファレンス

Leader キーは `\`（バックスラッシュ）。

## 基本キーマップ（lua/core/keymaps.lua）

### 移動

| キー | モード | 動作 |
|------|--------|------|
| `j` / `k` | Visual | 表示行単位で移動（折り返し行対応） |
| `↑` / `↓` | Normal, Visual | j / k にリマップ |

### 編集

| キー | モード | 動作 |
|------|--------|------|
| `Y` | Normal | カーソル位置から行末までヤンク |
| `Q` | Normal | テキスト整形（gq） |
| `>` | Normal | 1行インデント |
| `<` | Normal | 1行アンインデント |
| `>` | Visual | インデント（選択維持） |
| `<` | Visual | アンインデント（選択維持） |

### エスケープ

| キー | モード | 動作 |
|------|--------|------|
| `jj` | Insert | ノーマルモードに戻る |
| `jj` | Command | コマンドラインモードを抜ける |

### 無効化

| キー | モード | 理由 |
|------|--------|------|
| `s` | Normal | ddu のプレフィックスとして予約 |
| `ZZ` | Normal | 誤操作防止（保存して終了を防ぐ） |

## ddu.vim — ファジーファインダー / ファイラー

### 起動キー

| キー | 動作 |
|------|------|
| `sn` | ファイラー（カレントディレクトリを画面下スプリットで表示） |
| `sN` | カレントバッファのディレクトリでファイル検索 |
| `s;` | バッファ一覧 |
| `sm` | バッファ + 最近開いたファイル（MRU） |
| `s/` | 現在のバッファ内の行検索 |
| `sg` | grep 検索（パターンを入力 → ripgrep で検索） |

### ddu バッファ内操作

| キー | 動作 |
|------|------|
| `Enter` | 選択したアイテムを開く |
| `Space` | アイテムの選択/解除をトグル |
| `i` / `a` | フィルター（絞り込み）ウィンドウを開く |
| `p` | プレビュー表示 |
| `q` | ddu を閉じる |
| `Ctrl+c` | ddu を閉じる |
| `Ctrl+j` / `Ctrl+k` | 上下移動 |

### ddu フィルターウィンドウ内

| キー | モード | 動作 |
|------|--------|------|
| `Enter` | Insert | フィルターウィンドウを閉じる（結果一覧に戻る） |
| `Ctrl+c` | Insert, Normal | ddu を閉じる |

### ddu ファイラー内操作

| キー | 動作 |
|------|------|
| `Enter` | ファイルを開く |
| `l` | ディレクトリを展開/折りたたみ |
| `h` | 親ディレクトリに移動 |
| `Space` | アイテムの選択/解除をトグル |
| `c` | コピー |
| `p` | ペースト |
| `d` | 削除 |
| `r` | リネーム |
| `t` | 新規ファイル作成 |
| `mk` | 新規ディレクトリ作成 |
| `q` / `Ctrl+c` | ファイラーを閉じる |

## nvim-cmp — 補完

### 補完操作（挿入モード）

| キー | 動作 |
|------|------|
| `Tab` | 次の候補を選択 |
| `Shift+Tab` | 前の候補を選択 |
| `Enter` | 候補を確定 |
| `Ctrl+n` | 次の候補を選択 |
| `Ctrl+p` | 前の候補を選択 |

| `Ctrl+e` | 補完を中止 |

### 補完ソース

| cmp-vsnip | スニペット補完 |
| cmp-buffer | バッファ内のテキスト |
| cmp-path | ファイルパス補完 |

## LSP

LSP が接続されたバッファで有効。接続状況は `:LspInfo` で確認。

### コード移動

| キー | 動作 |
|------|------|
| `fd` | 定義にジャンプ |
| `fD` | 宣言にジャンプ |
| `fi` | 実装にジャンプ |
| `fr` | 参照一覧を表示 |
| `ft` | 型定義にジャンプ |

### ドキュメント

| キー | モード | 動作 |
|------|--------|------|
| `Space` | Normal | ホバードキュメント表示 |
| `Ctrl+k` | Insert | シグネチャヘルプ表示 |

### コードアクション

| キー | 動作 |
|------|------|
| `\rn` | シンボルのリネーム |
| `\ca` | コードアクション（Quick Fix 等） |
| `\f` | バッファ全体をフォーマット |

### 診断（エラー・警告）

| キー | 動作 |
|------|------|
| `[d` | 前の診断にジャンプ |
| `]d` | 次の診断にジャンプ |
| `\e` | カーソル位置の診断をフロート表示 |

### LSP 管理コマンド

| コマンド | 動作 |
|---------|------|
| `:Mason` | Mason UI を開く（LSP サーバーの管理） |
| `:LspInfo` | 接続中の LSP サーバーを表示 |

自動インストール対象: `pyright`（Python）, `ts_ls`（TypeScript）, `clangd`（C/C++）

## Git

### vim-fugitive

| キー | 動作 |
|------|------|
| `gs` | Git status（ステージング操作も可能） |
| `gd` | 現在のファイルの diff を分割表示 |
| `gb` | Git blame（行ごとの最終変更者） |
| `gl` | Git log（1行表示） |

Git status バッファ内：`s` でステージ、`u` でアンステージ、`cc` でコミット。

### gitsigns.nvim

signcolumn（左端）に Git 差分マークを自動表示：
- `+` 追加行
- `~` 変更行
- `_` 削除行

## テキスト編集

### Comment.nvim — コメントトグル

| キー | モード | 動作 |
|------|--------|------|
| `gcc` | Normal | 現在行のコメントをトグル |
| `gc` + モーション | Normal | 範囲コメント（例: `gcip` でパラグラフ） |
| `gc` | Visual | 選択範囲をコメントトグル |

JSX/TSX 等の埋め込み言語では、ts-context-commentstring により
正しいコメント構文（`//`, `{/* */}` 等）が自動選択される。

### nvim-surround — 囲み操作

| キー | 動作 | 例 |
|------|------|----|
| `ys{motion}{char}` | 囲みを追加 | `ysiw"` → `word` → `"word"` |
| `ds{char}` | 囲みを削除 | `ds"` → `"word"` → `word` |
| `cs{old}{new}` | 囲みを変更 | `cs"'` → `"word"` → `'word'` |

### nvim-autopairs — 自動括弧閉じ

`(`, `[`, `{`, `'`, `"` を入力すると自動で閉じ括弧が挿入される。
閉じ括弧の上で入力するとスキップ、`BS` で対の括弧も削除。

### in-and-out.nvim — 括弧脱出

| キー | モード | 動作 |
|------|--------|------|
| `Ctrl+Enter` | Insert | 括弧・引用符の外にジャンプ |

## 表示・UI

### fidget.nvim — 通知 + LSP 進捗

`vim.notify` の出力と LSP サーバーの起動・処理状況が右下にスピナーで表示される。
dpp のインストール/更新進捗もここに表示される。

### hlchunk.nvim — インデントガイド

カーソル位置のコードブロックが線で可視化される。

### numb.nvim — 行番号プレビュー

`:123` と入力中にその行がリアルタイムでプレビュー表示される。

### marks.nvim — マーク可視化

`m` + 文字で設定したマークが signcolumn に表示される。

### hlargs.nvim — 引数ハイライト

関数の引数が異なる色でハイライト表示される。

### ccc.nvim — カラーピッカー

| キー | 動作 |
|------|------|
| `\cc` | カラーピッカーを開く |
| `\ch` | バッファ内のカラーコードのハイライト表示を切替 |

## フォーマッター — conform.nvim

### 自動フォーマット

以下のファイルタイプは保存時に `prettierd` で自動フォーマットされる：

- TypeScript / JavaScript（.ts, .tsx, .js, .jsx）
- HTML / CSS
- JSON
- Markdown

### 手動フォーマット

| キー | 動作 |
|------|------|
| `\f` | バッファ全体をフォーマット（LSP fallback） |

`prettierd` は `:MasonInstall prettierd` でインストール。

## ターミナル・コード実行 — toggleterm.nvim

### ターミナル操作

| キー | モード | 動作 |
|------|--------|------|
| `Ctrl+\` | Normal | ターミナルの表示/非表示をトグル |
| `Esc` | Terminal | ターミナル内でノーマルモードに戻る |
| `jj` | Terminal | ターミナル内でノーマルモードに戻る |

### コード実行

| キー | 動作 |
|------|------|
| `\rt` | カレントファイルを実行（.ts → `npx tsx`, .js → `node`） |
| `\rs` | `npm start` を実行（プロジェクトルート自動検出） |
| `\rr` | `npm test` を実行 |

プロジェクトルートは `package.json` の位置から自動検出される。
TypeScript の直接実行には `tsx` が必要: `npm install -g tsx`

## Treesitter

### コマンド

| コマンド | 動作 |
|---------|------|
| `:TSInstall {lang}` | 指定言語のパーサーをインストール |
| `:TSUpdate` | インストール済みパーサーを一括更新 |

自動インストール対象: typescript, tsx, lua, toml, html, css, javascript, json, markdown, vim, python, cpp, c

### nvim-ts-autotag

HTML/JSX ファイルでタグの自動閉じ・リネーム連動が有効。
`<div` と入力すると `</div>` が自動挿入される。
